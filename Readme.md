## このツールのライセンス

色々なところからデータセットを持ってきていて、権利周りがややこしいので、このツールの再配布等は原則不可とします。

強い希望があれば個別にご相談ください。

私が書いたコード（`/src` 以下）の一部を参考にするとかはご自由にどうぞ。また、 ExifReader を含むバンドル（`/assets/exif-*.js`）については、 MPL ライセンスのもと再配布等可能とします。
