ARGTOOLS - 謎解き・データ解析の万能アシスタント

データ解析・暗号解読ツールの集合体です。データを入力すると、自動で使えるツールを推薦します。

各種 ARG、高難易度謎解き、CTF、開けないファイルの解析などにどうぞ。

実装されているツール一覧
画像解析
高度なカラー補正、画像ステガノグラフィ検査、メタデータ (Exif 等) 抽出
音声解析
音量を最大化、逆再生する、波形を描画、スペクトログラム解析
映像解析
音声データを抽出、超スロー再生
バイナリ解析
Zip ファイルを解凍、Gzip ファイルを解凍、zilb データを復号化、ビット演算で合成、数値として解釈、文字列データを抽出、結合する、バイナリを可視化
テキスト解析
Unicode の数値参照を読み取り、ISBN 番号を抽出、Punycode を読み取る、パーセントエンコードを読み取り、plus code を抽出、モールス信号を復号化、Base64 を読み取り、ROT13・Atbash 暗号を復号化、ROT47 暗号を復号化、シーザー暗号を復号化、数値（十進数）を抽出、数値（十六進数）を抽出、バイナリ（十六進数）を抽出、ポケベル入力を読み取り、YouTube の動画 ID を抽出、電話のダイヤル音を再現（DTMF）、○○文字目で改行、１行にまとめる、文字化けを復元、全角英数を半角に統一、反転する、生バイナリとして解析
数値解析
素因数分解する
提案
💡 what3words で検索、💡 Wolfram Alpha で計算、💡 Google で検索・翻訳、💡 Google Lens で検索、💡 ChatGPT と相談
謎解き制作支援
画像を音声に埋め込む
その他・便利機能
ファイル形式の自動判別、条件に一致する単語や地名の特定、プログラミング言語・自然言語の自動推定、文字数カウンタ、センターキャンセル
