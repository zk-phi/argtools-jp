ARGTOOLS - 謎解き・データ解析の汎用アシスタント（ベータ）

各種 ARG、高難易度謎解き、CTF などで使えそうな解析ツールの複合体です。

さまざまな解析器や変換器を組み合わせて、謎を解明するサポートをします。

実装されている変換器・解析器
画像解析
画像ステガノグラフィ検査、メタデータ (Exif 等) 抽出
音声解析
音量を最大化、逆再生する、波形を描画、スペクトログラム解析
映像解析
音声データを抽出、超スロー再生
バイナリ解析
Zip ファイルを解凍、Gzip ファイルを解凍、zilb データを復号化、ビット演算で合成、数値として解釈、文字列データを抽出、結合する
テキスト解析
Unicode の数値参照を復号化、ISBN 番号を抽出、Punycode を復号化、パーセントエンコードを復号化、plus code を抽出、モールス信号を復号化、Base64 を復号化、ROT13・Atbash 暗号を復号化、ROT47 暗号を復号化、シーザー暗号を復号化、数値（十進数）を抽出、数値（十六進数）を抽出、バイナリ（十六進数）を抽出、ポケベル入力を復号化、YouTube の動画 ID を抽出、電話のダイヤル音を再現（DTMF）、○○文字目で改行、１行にまとめる、文字化けを復元、全角英数を半角に統一、反転する、生バイナリとして解析
他
文字列を追加、ファイルを追加
提案
💡 what3words で検索、💡 Wolfram Alpha で計算、💡 Google で検索・翻訳、💡 Google Lens で検索、💡 ChatGPT と相談
その他
ファイル形式の自動判別、条件に一致する単語や地名の特定
